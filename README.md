# didactic-invention

A Python package scaffold for the didactic invention project.

## Getting started

1. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
2. Install the package in editable mode:
   ```bash
   pip install -e .
   pip install -r requirements-dev.txt
   ```
3. Run the sample entry point:
   ```bash
   python -m didactic_invention.main --name "Alice"
   ```
4. Run tests:
   ```bash
   python -m pytest
   ```
